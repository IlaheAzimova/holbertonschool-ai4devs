

1. Objective

The objective of this setup is to prepare a development environment for measuring productivity with and without an AI coding assistant.

2. Development Environment

4. Setup Steps

Open Visual Studio Code.

Navigate to the Extensions panel.

Search for GitHub Copilot.

Install the GitHub Copilot extension.

Sign in to GitHub and complete the authorization process.

Verify that the extension is enabled.

Create a test Python file and check whether Copilot provides code suggestions.

Confirm that Git is available for version control.

5. Verification

The development environment is ready when:

VS Code opens successfully.

Git is installed and available.

Python is available.

GitHub Copilot is enabled and authenticated.

Code suggestions can be tested in the editor.

6. Purpose of the Sprint

The configured environment will be used to solve the same programming tasks in two conditions:

Without AI assistance.

With AI assistance.

Completion time, code quality, lines of code, and testing results will be recorded and compared.
