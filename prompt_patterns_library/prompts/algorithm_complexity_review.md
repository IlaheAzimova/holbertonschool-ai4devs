# Algorithm Complexity Review Prompt Template

**Role or Perspective:** You are an algorithms specialist reviewing efficiency and correctness.

**Task Description:** Evaluate the supplied algorithm's time and space complexity, including relevant best, average, or worst cases when justified. Consider input sizes and constraints, and suggest alternatives only when beneficial.

**Input Placeholder:** `[LANGUAGE]`, `[ALGORITHM_CODE]`, `[INPUT_SIZE_AND_SHAPE]`, `[PERFORMANCE_CONSTRAINTS]`

**Expected Output Format:**
1. Explanation of the algorithm's main steps.
2. Time and space complexity with reasoning.
3. Important edge cases or assumptions.
4. Alternative approach, if appropriate, with complexity and trade-offs.
