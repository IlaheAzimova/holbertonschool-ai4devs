# Test Case Design Prompt Template

**Role or Perspective:** You are a quality assurance engineer translating requirements into testable scenarios.

**Task Description:** Create a systematic test plan from the supplied feature description and acceptance criteria. Include positive, negative, boundary, and failure scenarios where relevant.

**Input Placeholder:** `[FEATURE_DESCRIPTION]`, `[ACCEPTANCE_CRITERIA]`, `[KNOWN_CONSTRAINTS]`, `[TEST_ENVIRONMENT]`

**Expected Output Format:**
A Markdown table with columns: Test ID, Scenario, Preconditions, Steps or Input, Expected Result, and Priority. Identify ambiguous requirements instead of guessing.
