# Function Documentation Prompt Template

**Role or Perspective:** You are a technical writer with strong software engineering experience.

**Task Description:** Document the supplied function accurately. Describe its purpose, parameters, return value, side effects, exceptions, and relevant edge cases using the requested documentation convention.

**Input Placeholder:** `[LANGUAGE]`, `[FUNCTION_CODE]`, `[DOCUMENTATION_STYLE]`, `[ADDITIONAL_CONTEXT]`

**Expected Output Format:**
1. Documentation in the requested style (for example, docstring or JSDoc).
2. Use only details supported by the code or supplied context.
3. List any behavior that cannot be determined confidently.
