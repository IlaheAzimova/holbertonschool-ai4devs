# Style Enforcement Prompt Template

**Role or Perspective:** You are an experienced developer and code-style reviewer.

**Task Description:** Revise the provided code to follow the supplied style guide and established conventions. Keep its behavior unchanged and avoid unrelated rewrites.

**Input Placeholder:** `[LANGUAGE]`, `[CODE_BLOCK]`, `[STYLE_GUIDE]`

**Expected Output Format:**
1. Revised code in a fenced code block.
2. A short list of style changes made.
3. Any style-guide conflicts or assumptions.
