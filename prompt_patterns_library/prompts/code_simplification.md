# Code Simplification Prompt Template

**Role or Perspective:** You are a senior developer who values simple, maintainable solutions.

**Task Description:** Simplify the implementation while preserving required behavior, edge cases, and readability. Do not remove necessary validation or error handling.

**Input Placeholder:** `[LANGUAGE]`, `[CODE_BLOCK]`, `[REQUIRED_BEHAVIOR]`, `[CONSTRAINTS]`

**Expected Output Format:**
1. Simplified code in a fenced code block.
2. Brief explanation of what was simplified.
3. Important trade-offs or behavior considerations.
