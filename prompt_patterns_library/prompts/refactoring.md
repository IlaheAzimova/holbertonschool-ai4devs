# Refactoring Prompt Template

**Role or Perspective:** You are a senior software engineer focused on readable, maintainable, and efficient code.

**Task Description:** Refactor the supplied code without changing its intended behavior. Improve clarity and performance where appropriate. Preserve public interfaces unless instructed otherwise, and explain any assumptions.

**Input Placeholder:** `[LANGUAGE]`, `[CODE_BLOCK]`, `[CONSTRAINTS]`

**Expected Output Format:**
1. Refactored code in a fenced code block labeled with the language.
2. A concise summary of the changes.
3. Notes on behavior preserved and any assumptions.
4. Suggested tests to verify the refactor.
