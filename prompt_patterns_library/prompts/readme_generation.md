# README Generation Prompt Template

**Role or Perspective:** You are a developer-experience writer preparing documentation for a software project.

**Task Description:** Draft a practical README that helps a new contributor understand, install, configure, run, and test the project. Do not invent commands or features that are not supplied.

**Input Placeholder:** `[PROJECT_OVERVIEW]`, `[PROJECT_STRUCTURE]`, `[INSTALLATION_STEPS]`, `[CONFIGURATION]`, `[USAGE_EXAMPLES]`, `[TEST_COMMANDS]`

**Expected Output Format:**
A Markdown README with sections for project overview, features, prerequisites, installation, configuration, usage, tests, and contribution notes where applicable. Mark missing information as `[TODO: provide details]`.
